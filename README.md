# St. Mary's Malankara Syriac Orthodox Church — Oslo, Norway

Website for the Malayalam-speaking Malankara Syriac Orthodox parish in Oslo, Norway.

**Live site:** [stmarysmsoc.no](https://www.stmarysmsoc.no)

## About

St. Mary's MSOC Norway is a Malankara Syriac Orthodox parish serving the Malayali Orthodox community in Scandinavia since 2010. The parish holds Holy Qurbana, Oshana, Perunnal feasts, and Sunday School services at Eikeli Katolske Kirke, Veståsen 18, 1362 Oslo.

- **Vicar:** Rev Fr. Eldhose Vattaparambil
- **Diocese:** Malankara Syriac Orthodox Church — European Diocese

## Tech Stack

- [Jekyll](https://jekyllrb.com/) — static site generator
- GitHub Pages — hosting
- Multilingual: English (`en/`), Norwegian (`no/`), Malayalam

## Local Development

See [LOCAL_DEVELOPMENT_SETUP.md](LOCAL_DEVELOPMENT_SETUP.md) for full setup instructions.

Quick start:

```bash
bundle install
bundle exec jekyll serve
```

Then open [http://localhost:4000](http://localhost:4000).

## Project Structure

```
_config.yml          # Site configuration
_layouts/            # Page templates
_includes/           # Reusable partials (header, footer, schema, etc.)
_posts/              # News / announcements
_data/               # Structured data (YAML)
assets/              # CSS, JS, images
en/                  # English pages
no/                  # Norwegian pages
```
